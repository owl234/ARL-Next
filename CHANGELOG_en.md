## [v1.5.1] - 2026-11-21

### 🚀 New Features
- **Unified 26-dimension cascade deletion engine, derived rebuilds, and 7 KeepAlive view synchronization**: added `asset_cascade_service.py` to unify cascade cleanup across asset groups, seed targets, tasks, continuous monitors, and all 26 asset dimension delete endpoints (500-item batch limit) with explicit-binding isolation, L1/L2/L3 dependency rules, orphan IP reclamation with CIDR protection, endpoint-level service stripping, and case-insensitive `dict`/`str` fingerprint removal; rebuilt `cip`/`asset_cip`, `stat_finger`/`asset_stat_finger`, and `service`/`asset_service` from surviving host tables with cross-process cache invalidation via `system_config` version counters; added `POST /api/stat_finger/delete/`, optional `scope_id` concurrent 13-collection counting on `/api/asset_overview/count`, and `del_synced_asset` on `POST /api/task/delete/`; synchronized 7 KeepAlive views (Asset Group Details, Task Details, Asset Search, Asset Groups, Task List, Planning & Monitoring, and Dashboard) via `assetMutationVersion`, `deletedScopeIdSet`, cross-page selection confirmation lists (first 20 items expandable), and empty-page clamping.
- **Unified per-endpoint service view fusing Nmap and Python plugin services**: added `service_fusion.py` to merge Nmap port scan results, site feedback, Python plugin detections, and scope derived rebuilds per `(ip, port_id)` endpoint, calibrating weak labels such as `unknown` with protocol handshake results while preserving `product`, `version`, and multi-source tags (`sources`); deduplicated global `/api/service/` queries across tasks by `(ip, port_id)` in parity with `/api/asset_overview/count` and added `/api/service/export/` and `/api/asset_service/export/`; aligned Asset Search, Asset Group Details, Task Details, and `ChainDrawer.vue` on 12 asset dimensions and a single per-endpoint service table, removing secondary engine toggles and the retired `ServiceDetailModal.vue`.
- **Unified single-table schedule center and immediate scheduled task dispatch**: refactored `PlanningTasks.vue` to merge scheduled scans and continuous asset monitors into one table with semantic capsule tags for 6 schedule subtypes and a 3-tier header matching TaskList (top category capsules, 4 clickable status metric cards, filter bar, and floating batch bar); added `POST /api/task_schedule/run/` supporting manual immediate dispatch from any schedule status (atomically incrementing `run_number` only after dispatch succeeds), enriched `GET /api/scheduler/` with `scope_name`, and pre-filtered eligible rows for batch stop/resume with skipped-count notices.
- **Unified discovery and update timestamps across 12 dimensions**: standardized `save_date` and `update_date` across all 26 asset collections (13 task + 13 asset-group collections) as local-timezone BSON `datetime`, exposing `save_date` range filtering and sorting on all 26 routes (plus `update_date` on asset-group routes), timezone-aware ISO 8601 boundary normalization, and consistent post-grouping min/max time filtering and export parity across global aggregated views (`service`, `cip`, `stat_finger`); added `AssetTimeCell.vue` and full-day single-date range normalization across Asset Search, Asset Group Details, Task Details, and the asset profile drawer.

### 🛠️ Performance & Refactoring
- **MongoDB connection pool tuning, lean indexing, and idempotent migration hardening**: standardized `MongoClient` pool defaults, removed `cip` array multikey indexes and conflicting/redundant indexes, and enabled `allowDiskUse=True` across global aggregation pipelines; added three `system_config` sentinel-guarded one-time idempotent migrations in `arlupdate.py`—two-phase unified service expansion (upserting before removing legacy grouped documents, preserving `_id`-derived `save_date`, and skipping unique index creation if migration does not complete), cascade/derived self-healing, and batched discovery-timestamp backfilling—while serializing deferred startup migrations on a single delayed thread to avoid Gunicorn preload fork races.
- **Retirement of unused `port_top_10` setting and default port type convergence**: removed the unread `port_top_10` setting across the UI, config API, `Config.TOP_10`, and orphaned helpers/i18n keys, switching the `port_scan` fallback to the Top100 dictionary; converged internal default `port_scan_type` from `test` to `top100` while retaining the `test` alias for backward compatibility.
- **Bilingual documentation overhaul and UI screenshot refresh**: rewrote Chinese and English `README` files around user workflows, refreshed Dashboard, Task Creation, System Settings, Threat Intel Radar, and MCP Center screenshots, fixed preview card cropping in `tools/make_social_preview.py`, and updated bilingual `docs/API_GUIDE*.md` and `mcp-server/README*.md`.

### 🐛 Bug Fixes & Hardening
- **Task option summary filtering and root domain source attribution**: added parent-switch filtering in backend startup logging (`celerytask.py`) and frontend option details (`TaskList.vue`) so dependent dictionary/port parameters for disabled stages (`domain_brute`, `alt_dns`, `port_scan`, `file_leak`) are hidden; corrected root domain source attribution from `domain_brute` to `target` (`CollectSource.TARGET`) when `domain_brute` is disabled.
- **Asset group lifecycle closure, in-flight task revocation, and survival guards**: stopped active enterprise recon updates (`updating_icp_task_id`) and cleared scope bindings upon asset group deletion while preserving raw recon records; propagated scope renames to linked monitors and tasks; revoked in-flight monitor tasks and reset `next_run_date` on single/batch stop; added pre-commit scope/target survival checks in `SyncAsset` and monitor pipelines; guarded malformed IP strings during CIDR cascade delete and rebuilt unified `service` collections cleanly on `npoc_service` deletion.
- **Frontend asset views, search, and schedule center regression fixes**: replaced missing batch-delete i18n keys in `AssetSearch.vue`; fixed `GroupAssetsDetail.vue` double-counting `npoc_service` in totals, filtered fetches overwriting tab badge counts, WIH `source` column colliding with domain sources, missing count/mutation refreshes after adding sites or domains, and incomplete selection clearing; fixed `PlanningTasks.vue` category-switch selection clearing, error swallowing and failed-selection clearing during batch actions, row stop button wording unification, and policy list refresh on KeepAlive reactivation; synchronized legacy unit test fixtures and added pre-release regression suites.

### 🛡️ Security & Configuration
- **Fail-closed POST endpoints for selected-row risk cruising**: added `POST /api/site/save_result_set/` and `POST /api/asset_site/save_result_set/` accepting JSON `_id` arrays with strict non-empty, ObjectId validity, and 500-item limit checks (returning business `code: 400` on invalid input to prevent fallback broad scans); updated `AssetSearch.vue`, `TaskDetail.vue`, and `GroupAssetsDetail.vue` to submit selected rows via POST and abort opening the modal on non-200 responses.
- **External link hardening, MCP E2E credential isolation, and factual doc alignment**: added `isHttpUrl` validation and `rel="noopener noreferrer"` to WIH source links in `GroupAssetsDetail.vue`; explicitly injected ephemeral test keys into the Stdio subprocess in `tools/verify_mcp_e2e.py` to avoid local admin credential shadowing; aligned bilingual `API_GUIDE` and `mcp-server/README` docs on self-signed `ARL_CA_BUNDLE` configuration, Nuclei protocol block boundaries, and RFC 5737 placeholder examples, keeping dual copies `mcp-server/server.py` and `frontend/public/mcp/server.py` identical.
